**Functional Requirements**
- The app has to know who someone is when they come back, so they stay logged in on their device 
- Each person's data has to be stored somewhere that isn't my laptop, and kept separate from everyone elses
- When someone submits an answer, it has to be saved 
- Claude's questions and insights have to be generated by code running somewhere private, so my API key is never exposed 
- Current statistics have to be calculated from the saved answers and shown on screen
- Insights and scores have to be saved so people can reopen them later, along with whether they clicked done 
- Someone has to look across many saved answers over time, find tags and trends, and save the results 

**Supabase**
Q1: Every project is a full Postgres database with auth, storage, and functions. The database will cover the saved answers, statistics, and insights and scores. 

Q2: I can choose from a variety of front ends

Q3: The software uses Edge functions which are typescript, not python. 

Q4: There is a free tier that pauses projects after a week of inactivity. The data survives but it would look bad if the app is paused during a demo, but for the purpose and audience being me, it may not matter as much. Pro is $25 per month plus usage.


**Firebase**
Q1: Default database and a login systems, and cloud functions run server-side code. This applies to functional requirements 1-4. It has count, sum, and average aggregates, which helps with grouping. 

Q2: I can choose from a variety of front ends. Next.js guides exist. 

Q3: Free plan does not include Cloud functions, and it is a NoSQL database, not relational. 

Q4: Free plan, which does not include Cloud functions, which I require. Free quotas reset daily


**Next.js**
Q1: A react framework with file-based routing for backend endpoints in the same project. It does not appear to provide a database or login but functions with various backends.

Q2: It chooses React.

Q3: It is a JavaScript / TypeScript, so Python would be separate. 

Q4: it is open source but hosting matters.
